# Vice Nights — a GTA 6-style cover art maker

Turn a photo (or three) and a caption into a multi-panel poster in the
Vice City sunset style: angled photo panels, a striped neon sun, a
purple skyline, bold condensed lettering and a script tagline. Export
as a PNG in 1080 x 1080, 1080 x 1350 or 1920 x 1080.

## Use it

1. Pick a post size.
2. Load photos into slots 1-3 (your own files, or the free samples).
3. Assign a photo to each panel, click a panel in the preview to select
   it, then drag it to position the photo and use the zoom slider.
4. Type the title and the tagline, set the sunset grade, export.

Everything runs offline in the browser: photos are read on your own
machine and never uploaded.

## Original art

All lettering uses fonts shipped under `app/fonts/` under the SIL Open
Font License 1.1 (see `OFL.txt`): Anton for the title, Pacifico for
the tagline. The sunset, sun, skyline and palms are drawn by the app
itself in `src/cover.js`. No Rockstar Games logo, artwork, character
or font is used anywhere.
