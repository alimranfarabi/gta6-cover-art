# Vice Nights

An entry for the make.fun bounty [Make GTA 6 Cover Art](https://make.fun/bounty/gta6-cover-art-01).

Vice Nights is a static, offline web app that turns your photos and a caption
into multi-panel GTA 6-style cover art. Three angled photo panels sit over a
hand-drawn Vice City sunset — striped neon sun, lit-window skyline, palm
silhouettes, vignette and grain. Each panel can hold its own photo (upload one
or use the free samples), with drag-to-pan and zoom, and the caption (bold
title + tagline) and sunset grade are editable in a live preview.

One click exports the cover as a PNG in 1080x1080, 1080x1350 or 1920x1080.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
